# 🎮 Clone da PlayStation Store

Este projeto é um clone simples da PlayStation Store desenvolvido com **Angular 17**, com foco em praticar conceitos modernos de desenvolvimento front-end e criar uma interface limpa e funcional inspirada na loja oficial da Sony.

![Angular](https://img.shields.io/badge/Angular-17-red)
![License](https://img.shields.io/github/license/robsonosbor/clone-playstation-store)
![GitHub repo size](https://img.shields.io/github/repo-size/robsonosbor/clone-playstation-store)

## 🧰 Tecnologias Utilizadas

- [Angular 17](https://angular.io/)
- [TypeScript](https://www.typescriptlang.org/)
- [RxJS](https://rxjs.dev/)
- HTML5 & CSS3

## 🚀 Funcionalidades

- Listagem de jogos com imagens e preços
- Design inspirado na UI/UX da PlayStation Store
- Layout responsivo
- Roteamento de páginas com Angular Router

## 📦 Como rodar o projeto

1. **Clone o repositório:**

```bash
git clone https://github.com/robsonosbor/clone-playstation-store.git
cd clone-playstation-store
```

2. **Instale as dependências:**

```bash
npm install
```

3. **Rode o projeto localmente:**

```bash
ng serve
```

4. Acesse no navegador:  
`http://localhost:4200`
